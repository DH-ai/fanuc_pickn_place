# Documentation

This directory contains technical documentation for the FANUC Pick-and-Place system. Each subfolder focuses on a specific subsystem or operational aspect of the project.

## Directory Structure

```text
docs/
├── gripper/
├── troubleshooting/
├── vision/
└── README.md
```

## Contents

### 📁 [`gripper/`](https://github.com/DH-ai/fanuc_pickn_place/tree/main/docs/gripper)

Documentation related to the end-effector and gripping mechanism.

---

### 📁 [`vision/`](https://github.com/DH-ai/fanuc_pickn_place/tree/main/docs/vision_pipline)

Documentation for the computer vision pipeline used in the pick-and-place system.

---

### 📁 [`troubleshooting/`](https://github.com/DH-ai/fanuc_pickn_place/tree/main/docs/troublshoot.md)

Common issues encountered during setup, deployment, and operation, along with their solutions.
---

## Purpose

The documentation is intended to serve as a centralized knowledge base for developers, researchers, and operators working on the FANUC Pick-and-Place system. It should provide sufficient information to install, configure, operate, maintain, and troubleshoot the complete workflow.
